For analysts

A dataset by month, state, and year

The file is meant to be used. One row is one geography and one month. Finished months are the death certificate. Later months keep CDC's preliminary 12-month total, labeled as preliminary, so the series does not stop at the last final year. Column names are ordinary words.

This is the path for analysts and developers. Download the file if you want the numbers. Open the repository if you want the code that builds them. Either way, you can skip assembling CDC's SODA API and the WONDER request form yourself.

The file to start with

Download deaths_by_state_month.csv

The publish job runs every Monday, and again when this pipeline changes. If CDC has posted a new month, that month is in the file. If CDC has not, the newest month stays where CDC left it and the checked date moves forward. A state does not get an invented count for a single recent month. The United States row does, and it is marked "Preliminary estimate."

National months, one row per month

Download deaths_by_month.csv

A number below zero is not a count of deaths. It means a provisional total was revised. Deaths per 100,000 use a July 1 Census population. When that population is from a different year than the deaths, the note on the row names the Census year. An earlier Census year is carried forward when the new year is not in the file yet. The method is written out in monthly_deaths.md.
